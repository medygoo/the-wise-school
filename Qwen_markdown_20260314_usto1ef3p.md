# The Wise School International - Site Web

Site vitrine officiel pour le Complexe Scolaire Le Sage / The Wise School à Kinshasa.

## 🚀 Déploiement

### Option 1 : GitHub Pages
1. Créez un nouveau dépôt (repository) sur GitHub (ex: `the-wise-school`).
2. Téléchargez tous les fichiers de ce projet dans ce dépôt.
3. Allez dans **Settings** > **Pages**.
4. Sous "Source", sélectionnez la branche `main` (ou `master`) et le dossier `/ (root)`.
5. Cliquez sur **Save**. Votre site sera en ligne sous `https://votre-pseudo.github.io/the-wise-school/`.

### Option 2 : Netlify (Recommandé)
1. Connectez-vous sur [Netlify.com](https://www.netlify.com/).
2. Glissez-déposez le dossier contenant vos fichiers (le dossier racine du projet) dans la zone "Drag and drop your site folder here".
3. Le site est en ligne instantanément.

## 🌐 Configuration du Domaine Personnalisé
Si vous achetez un domaine (ex: `thewiseschool.cd`) :
1. Allez dans les paramètres de votre site sur Netlify/GitHub.
2. Cherchez la section "Domain Management".
3. Ajoutez votre domaine.
4. Suivez les instructions DNS (généralement un enregistrement CNAME ou A Record) fournies par votre hébergeur de domaine.

## 🖼️ Images
Les images actuelles sont des placeholders. Remplacez les fichiers dans le dossier `assets/images/` et mettez à jour les liens `src` dans le HTML.
